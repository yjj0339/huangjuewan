# 云桥叠翠 · 五层互通立交 3D

**在线体验：<https://yjj0339.github.io/huangjuewan/>**（部署后此行会自动生效）

参照重庆黄桷湾立交（5 层 · 20 条匝道 · 8 个方向）用 Three.js r170 程序化生成的
超大型多层城市互通立交桥写实 3D 场景。

## 场景构成

| 层 | 内容 | 标高 |
|----|------|------|
| 5 | 对角主线 D（西南—东北） | 36m |
| 4 | 对角主线 C（西北—东南） | 27m |
| 3 | 南北主线 B | 18m |
| 2 | 东西主线 A | 9m |
| 1 | 地面道路 + 绿地公园 | 0m |

- **20 条匝道**：8 条环形匝道（苜蓿叶式）、4 条定向半直接匝道、6 条落地匝道、**2 条螺旋匝道**（一升一降，地标级盘桥）
- **桥墩**：锥形方柱 + 盖梁 + 基座，沿线自动布桩并避让下方穿越桥面（数十根）
- **桥面**：程序化沥青纹理（车道线/车辙/裂缝/水渍）+ 混凝土纹理（模板缝/雨渍/锈渍）、金属护栏、路灯、门架标志牌
- **车流**：轿车/SUV/公交/货柜四类实例化车流，约 400+ 辆沿线网行驶
- **环境**：绿地公园（乔/灌木/池塘/步道）、远景城市 700+ 建筑与地标塔、渐变天空、云朵与漂移云影
- **渲染**：PBR 材质 + ACES 色调映射 + 4096 软阴影 + 雾景纵深，白天自然光

## 操作

- 左键拖拽旋转 · 滚轮缩放 · 右键平移
- 底部按钮切换镜头：鸟瞰全貌 / 桥下仰视 / 螺旋匝道 / 主线穿行 / 塔俯市景 / 北向远眺 / 自动环视

## 本地运行

```bash
node tools/server.js   # http://localhost:8918/
```

零依赖、零构建：`vendor/three.module.js` + 原生 ES Modules，全部纹理 Canvas 程序化生成。

## 技术要点

- 路网：参数化道路（直线/贝塞尔/圆弧/螺旋）+ 弧长参数化采样；匝道用"锚点自动对接"
  （起点/终点吸附目标道路采样点，位置标高切向自动吻合）
- 桥面：沿中心线扫描横断面（沥青顶板 + 腹板 + 底板 + 护栏断面 + 金属栏）生成 BufferGeometry
- 桥墩：空间网格碰撞检测避让下层桥面
- 车流：按车型 InstancedMesh + 顶点色 + 实例色，弧长推进
